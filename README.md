Force Former – Interactive Media Studio
Project Overview
This project was created for the Interactive Media Studio course. It uses the Force Former system in Godot to explore how forces and physical rules can interact within a digital environment.
Forces
Weather: Uses wind and rainfall to influence the environment.
Gravity: Adds gravitational force to affect objects and movement.
Project Development
I created and customized the Weather and Gravity forces, adjusted their settings, and used them to build my map. I tested the project in Godot to observe how the forces interact.
Tools Used
Godot Engine
Force Former
GitHub
Reflection
This project helped me learn how to work with forces and environmental effects in Godot. It also gave me experience with creating an interactive environment, testing my work, and sharing a project through GitHub.
